# Flash Web Center, LLC

Drupal websites, themes and modules, built and cared for in Austin, Texas.
Website: [FlashWebCenter.com](https://www.flashwebcenter.com) · Drupal.org: [flashwebcenter](https://www.drupal.org/u/flashwebcenter)

## Free Drupal projects

**Themes**
- [W3CSS Theme](https://www.drupal.org/project/d8w3css), with the sub-themes [Amun](https://www.drupal.org/project/amun), [Amunet](https://www.drupal.org/project/amunet) and [Anhur](https://www.drupal.org/project/anhur)
- [Solo](https://www.drupal.org/project/solo)

**Content building**
- [Paragraphs Bundles](https://www.drupal.org/project/paragraphs_bundles)
- [W3CSS Paragraphs](https://www.drupal.org/project/w3css_paragraphs)

**Views display formats** (Views Vanilla JavaScript, no jQuery)
- [VVJ Core](https://www.drupal.org/project/vvj_core) and its formats: carousels, sliders, slideshow, flip boxes, lightbox, parallax and more

**Site tools**
- [Selectify](https://www.drupal.org/project/selectify) · [Module Matrix](https://www.drupal.org/project/module_matrix) · [UtiliKit](https://www.drupal.org/project/utilikit) · [Cloudflare Purge](https://www.drupal.org/project/cloudflare_purge) · [Acquia Purge Varnish](https://www.drupal.org/project/acquia_purge_varnish)

Source mirrors of these projects live at [github.com/drupalcare](https://github.com/drupalcare). Issues and releases are on drupal.org.
